# TLS-007: TLS 1.3 not observed as supported

- **Area:** tls
- **Severity:** informational

## What is observed

The server did not accept a handshake pinned to TLS 1.3. Checked only with --probe-legacy-tls.

## Why it can matter

TLS 1.3 is the current protocol version. It removes older features that were a source of weaknesses and shortens the handshake. A server that does not accept it still works over TLS 1.2, which remains secure, so this is only a note.

## False positives

This is checked only when Sentinel runs with --probe-legacy-tls. A server whose software or library is too old to support TLS 1.3 matches, and so does one where TLS 1.3 was turned off on purpose. A failed probe can also come from a network problem rather than from missing support.

## How to fix

### nginx

```
# Needs nginx built with OpenSSL 1.1.1 or newer.
ssl_protocols TLSv1.2 TLSv1.3;
```

### Apache

```
# Needs Apache 2.4.36 or newer built with OpenSSL 1.1.1 or newer.
SSLProtocol -all +TLSv1.2 +TLSv1.3
```

### Caddy

```
# TLS 1.3 is enabled by default. If it was restricted, allow it again:
example.com {
    tls {
        protocols tls1.2 tls1.3
    }
}
```
