# HTTP-006: Version information observed in Server header

- **Area:** http
- **Severity:** informational

## What is observed

The Server header contains version-like text.

## Why it can matter

The Server header sometimes names the web server software together with its version. Knowing the exact version lets someone look up issues that were published for it, so removing the version detail gives away less. Keeping the software up to date matters more than hiding the version.

## False positives

The rule matches version-like text such as 2.4 or 1.18, not a confirmed software version, so a value that merely looks like a version can match. The header may come from a proxy or CDN in front of the server rather than from the origin server. Hiding the version does not change which version is running.

## How to fix

### nginx

```
# In the http block.
server_tokens off;
```

### Apache

```
# In the main server configuration, not in .htaccess.
ServerTokens Prod
ServerSignature Off
```

### Caddy

```
# Inside the site block.
header -Server
```
