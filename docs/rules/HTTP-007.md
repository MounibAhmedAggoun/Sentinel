# HTTP-007: Version information observed in X-Powered-By header

- **Area:** http
- **Severity:** informational

## What is observed

The X-Powered-By header contains version-like text.

## Why it can matter

The X-Powered-By header is often added by an application framework and names it, sometimes with a version. It tells an outside observer which technology is in use and can help them look up issues for that exact version. Keeping the software up to date matters more than hiding the header.

## False positives

The rule matches version-like text, so a value that only looks like a version can match. The header may be added by a layer in front of the application. Removing the header does not change what software is running.

## How to fix

### nginx

```
# Hides the header when it comes from a proxied application.
proxy_hide_header X-Powered-By;
# For FastCGI backends such as PHP-FPM:
# fastcgi_hide_header X-Powered-By;
```

### Apache

```
# Needs mod_headers.
Header always unset X-Powered-By
```

### Caddy

```
header -X-Powered-By
```

### Express

```
app.disable('x-powered-by');
```
