# DNS-001: SPF record not observed

- **Area:** dns
- **Severity:** low

## What is observed

No SPF record was seen in the TXT records of the scanned name.

## Why it can matter

SPF is a DNS record that lists which servers may send email for a domain. Receivers use it to spot forged mail. Without one, a receiver has no SPF information for the name, which matters most for domains that send or receive email.

## False positives

A name that never sends email, such as a host used only for a website, does not need an SPF record to work. Sentinel reads the TXT records of the scanned name only. A subdomain may send no mail while the organizational domain has a record. Sentinel skips this rule when the DNS server did not clearly answer, and for IP address targets.

## How to fix

### DNS zone (domain sends mail)

```
; List the servers that send mail. Replace the include with your provider.
example.com.  IN  TXT  "v=spf1 include:_spf.example.net ~all"
```

### DNS zone (domain sends no mail)

```
example.com.  IN  TXT  "v=spf1 -all"
```
