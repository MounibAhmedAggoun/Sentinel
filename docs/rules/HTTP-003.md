# HTTP-003: Security header not observed: X-Content-Type-Options

- **Area:** http
- **Severity:** low

## What is observed

The X-Content-Type-Options header was missing or not set to nosniff.

## Why it can matter

The value nosniff tells a browser to trust the content type the server declares, and not to guess a different one from the content. Without it, some browsers may treat a file as another type, which can reduce the protection that a correct content type gives.

## False positives

The practical effect on current browsers is small. The rule also reports a header that is present with a value other than nosniff, because only that exact value has the effect.

## How to fix

### nginx

```
add_header X-Content-Type-Options "nosniff" always;
```

### Apache

```
# Needs mod_headers.
Header always set X-Content-Type-Options "nosniff"
```

### Caddy

```
header X-Content-Type-Options nosniff
```

### Express

```
app.use((req, res, next) => {
  res.setHeader('X-Content-Type-Options', 'nosniff');
  next();
});
```
