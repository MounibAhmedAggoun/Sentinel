# HTTP-009: Strict-Transport-Security observed with a short or missing max-age

- **Area:** http
- **Severity:** low

## What is observed

The Strict-Transport-Security header has no max-age value, or one below 180 days.

## Why it can matter

Strict-Transport-Security tells a browser to use HTTPS only for the length of its max-age. A short max-age means the browser forgets the instruction sooner, and a header with no max-age value may be ignored by browsers. A longer value keeps visitors on HTTPS for longer between visits.

## False positives

A max-age of 0 is sometimes set on purpose, to make browsers forget an earlier HSTS setting while a site is being moved back to HTTP. A short value is also a reasonable choice while HSTS is being rolled out. Sentinel flags values below 180 days and reads one response only.

## How to fix

### nginx

```
add_header Strict-Transport-Security "max-age=31536000" always;
```

### Apache

```
# Needs mod_headers.
Header always set Strict-Transport-Security "max-age=31536000"
```

### Caddy

```
header Strict-Transport-Security "max-age=31536000"
```

### Express

```
app.use((req, res, next) => {
  res.setHeader('Strict-Transport-Security', 'max-age=31536000');
  next();
});
```
