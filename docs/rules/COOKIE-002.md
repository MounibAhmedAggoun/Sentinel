# COOKIE-002: Cookie flag not observed: HttpOnly

- **Area:** cookie
- **Severity:** low

## What is observed

A cookie has no HttpOnly flag.

## Why it can matter

The HttpOnly flag keeps a cookie out of reach of scripts running in the page. Without it, a script that gets injected into the page, for example through cross-site scripting, can read the cookie. This matters most for session cookies.

## False positives

Some cookies are meant to be read by page scripts, such as a token that a script copies into a request header. For those, the missing flag is intentional. Sentinel cannot tell which cookies are session cookies, and it only sees cookies set on anonymous requests.

## How to fix

### nginx

```
# For proxied applications. Needs nginx 1.19.3 or newer.
proxy_cookie_flags ~ httponly;
```

### Apache

```
# Needs mod_headers. Appends the flag to every cookie, so it can
# duplicate a flag the application already sets.
Header always edit Set-Cookie ^(.*)$ $1;HttpOnly
```

### Express

```
res.cookie('sid', value, { httpOnly: true });
```
