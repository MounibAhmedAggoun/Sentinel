# DNS-003: CAA record not observed

- **Area:** dns
- **Severity:** informational

## What is observed

No CAA record was seen for the scanned name or its parent domains.

## Why it can matter

A CAA record lists which certificate authorities may issue certificates for a domain. Authorities check it before issuing, so it limits who can obtain a certificate for the name. Without one, any authority may issue.

## False positives

CAA is optional, and many sites work well without it, which is why this is informational. Sentinel checks the scanned name and its parent domains, and stops at the first record set it finds. Some DNS hosts do not support CAA records.

## How to fix

### DNS zone

```
; Allow only the authority you use. Letsencrypt.org is an example.
example.com.  IN  CAA  0 issue "letsencrypt.org"
```
