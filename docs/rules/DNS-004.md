# DNS-004: SPF record observed that allows any sender

- **Area:** dns
- **Severity:** medium

## What is observed

The SPF record ends in +all, which permits any server to send mail for the domain.

## Why it can matter

An SPF record that ends in +all says that every server is allowed to send mail for the domain. That removes the point of SPF, because a receiver can no longer use it to tell real mail from forged mail.

## False positives

A +all ending is almost never intended. It can appear by mistake, for example from a template or a typo. Sentinel reads the final all mechanism of the record it found and does not follow include or redirect targets.

## How to fix

### DNS zone

```
; End the record with -all or ~all and list only the servers that send mail.
example.com.  IN  TXT  "v=spf1 include:_spf.example.net -all"
```
