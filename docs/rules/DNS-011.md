# DNS-011: DMARC record observed with a weaker subdomain policy

- **Area:** dns
- **Severity:** low

## What is observed

The DMARC sp tag sets a weaker policy for subdomains than the p tag sets for the domain.

## Why it can matter

The sp tag sets the DMARC policy for subdomains, and the p tag sets it for the domain itself. When sp ranks below p, for example p=reject with sp=none, mail that claims to come from a subdomain is handled less strictly than mail from the main domain. Without an sp tag, subdomains inherit p.

## False positives

A weaker subdomain policy is sometimes chosen on purpose, for example when some subdomains send mail through services that are not yet set up for DMARC. A subdomain that publishes its own DMARC record overrides sp. Sentinel reads the record found at the scanned name or the organizational domain, and does not check each subdomain separately.

## How to fix

### DNS zone

```
; Remove sp so subdomains inherit p, or set it equal to p.
_dmarc.example.com.  IN  TXT  "v=DMARC1; p=reject; sp=reject; rua=mailto:dmarc-reports@example.com"
```
