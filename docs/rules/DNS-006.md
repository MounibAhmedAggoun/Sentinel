# DNS-006: SPF record observed without an enforcing policy

- **Area:** dns
- **Severity:** low

## What is observed

The SPF record ends in ?all, or has neither an all mechanism nor a redirect.

## Why it can matter

An SPF record that ends in ?all, or that has neither an all mechanism nor a redirect, gives receivers no verdict for servers that are not listed. Mail from an unlisted server is then neither passed nor failed, so the record adds little protection.

## False positives

A neutral ending is sometimes used while SPF is being tested. A record with no all mechanism can be valid when it is meant to be combined with a redirect, and Sentinel checks for redirect= in the raw record. It does not follow include targets.

## How to fix

### DNS zone

```
; End the record with -all (fail) or ~all (soft fail).
example.com.  IN  TXT  "v=spf1 include:_spf.example.net ~all"
```
